# Мониторинг озеленения 2020–2026

Работа ведётся в существующем React/Leaflet/FastAPI MVP. Миграция инфраструктуры отменена и к этому модулю не относится. Публикация не выполняется.

## Реальные данные

Проверка 29.10.2026: Earth Search, коллекция `sentinel-2-l2a`, bbox `[76.925,52.265,76.985,52.310]`, периоды 1 июня — 31 августа. При фильтре облачности сцены <35% найдено 78 сцен за 2020 и 45 за 2026. Для одного снимка каждого года проверены B04, B08 и SCL: HTTP 206, настоящие TIFF-байты. Исходные ответы проверки: `output/qa/monitoring-source-check.json`.

Источник: [Sentinel-2 COGs / Element 84](https://registry.opendata.aws/sentinel-2-l2a-cogs/), свободный открытый доступ. Разрешение B04/B08 — 10 м, SCL — 20 м. Маска SCL переносится ближайшим соседом; это не увеличивает её фактическую детализацию. [Официальная спецификация каналов и SCL](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/S2L2A.html).

## Этапы и независимые области

1. GIS: `backend/monitoring/core.py`, `pipeline.py`, `scripts/build_monitoring.py`; реальная геообработка и тесты формул/масок.
2. Backend: `backend/monitoring/service.py`, `api.py`, `reports.py`; кеш, тайлы, статистика, отчёты, проверки API.
3. Frontend: `src/Monitoring*.tsx`, `monitoringTypes.ts`, `monitoring.css`; карта и сравнение.
4. AI: серверный инструмент `get_vegetation_change` и проверенный контекст выбранной зоны. Запускается после освобождения слота первой волны.
5. QA: сквозная проверка реальных данных, общих масок, статистики, экспорта и регрессий MVP.
6. Архитектор/root: контракт данных, интеграция маршрута/навигации, зависимости, запуск и итоговые ограничения.

## Контракт и достоверность

- Предварительно обрабатывается центр Павлодара с 12 существующими OSM-зонами; результаты не называются статистикой всего города.
- Одна привязанная к 10 м сетка EPSG:32643; NDVI двух лет и число пригодных наблюдений сохраняются в GeoTIFF.
- Несколько наблюдений на каждый сезон, медианный NDVI; для сравнения нужны минимум два пригодных наблюдения каждого года на пиксель.
- Маска качества исключает облака/тени/снег/дефектные/неопределённые пиксели. Все площади и средние считаются по общим пригодным пикселям обоих лет.
- Порог NDVI по умолчанию 0,3, настраивается. Переходы класса не означают доказанную посадку/вырубку деревьев.
- Радиометрическое смещение проверяется по baseline и `earthsearch:boa_offset_applied`; повторное вычитание смещения недопустимо. Неоднозначные данные должны быть отклонены с причиной.
- `manifest.json` получает статус ready только после успешной обработки обоих годов. Нет данных — null и понятная причина, без численных заглушек.
- Тяжёлый pipeline не запускается из HTTP запросов. Чтение готовых растров кешируется и ограничено обработанной областью.

## Критерии передачи

Идентификаторы реальных сцен и воспроизводимый запуск; проверенные сетки/маски/формулы; реальные тайлы и статистика для зоны; RU/KK PDF/Excel; контролируемый AI-контекст; тесты и прежний MVP работают. Отсутствие реального покрытия или доступа явно ограничивает статус готовности.
