# Архитектурные решения

- React + Vite и отдельный FastAPI соответствуют ТЗ. Sites-хостинг исполняет Cloudflare Workers, поэтому Python API будет подготовлен для Render, а клиент для Vercel/Firebase Hosting; локальный результат не называется опубликованным.
- SQLite для воспроизводимого бесплатного запуска; SQLAlchemy и миграции позволяют PostgreSQL. Геометрии хранятся как GeoJSON; измерения выполняет pyproj.Geod/Shapely. PostGIS подключается в Docker для дальнейших GIS-запросов.
- Локальная регистрация с scrypt и непрозрачными HttpOnly-сессиями работает без платных почтовых сервисов. Firebase Authentication — дополнительный путь входа, если провайдер email/password включён владельцем проекта. Роли определяет только API.
- Все расчёты детерминированы, версии справочников сохраняются вместе с проектами. Экспертные оценки не объявляются обученной моделью или фактическими измерениями.
- Бесплатный AI отделён от аналитики. Недоступность OpenRouter не мешает расчётам. Только модели :free с нулевой ценой всех тарифицируемых параметров, максимум 40 попыток в сутки по умолчанию.
- Публичная публикация требует доступов к аккаунтам; платные услуги и автоматические платные переключения запрещены.
- Для Shapefile используется лёгкий pyshp + pyproj вместо GeoPandas: ограниченные файлы MVP не требуют всего стека pandas/GDAL. Геометрия валидируется Shapely, CRS задаётся через обязательный .prj.
- При получении 429 пауза Retry-After применяется консервативно ко всему AI-роутеру, так как ограничение может относиться к аккаунту. Бесплатный openrouter/free предпочитается только при подтверждённой нулевой цене в каталоге.
- Подготовка почвы считается по реальному footprint посадочного плана (количество × шаг²); доступная под озеленение площадь задаёт верхнюю границу, а не обязательные расходы.

## Уточнения карты и AI, 29.10.2026
- Вместо шести условных прямоугольников используются 8 именованных парков/скверов по реальным замкнутым контурам OSM и 4 открытых территории OSM с предварительным статусом кандидата для обследования.
- «Уже озеленено» означает отображение объекта, отмеченного зелёной территорией в OSM; не означает проведённую инвентаризацию или известное количество деревьев. «Предлагается посадка» — проектное предложение, а не подтверждённая обязанность или разрешение на работы.
- Личные названия отделены от канонических OSM ID и источника. Гость сохраняет название в localStorage, пользователь — в Setting с ключом, привязанным только к своему аккаунту; изменение публичных названий не разрешается этим API.
- Нажатие зоны открывает короткую карточку и «Спросить ИИ». Кнопка переносит выбор и готовит вопрос, но не расходует квоту до отправки.
- Выбор сохраняется в sessionStorage и параметре zone URL; пользовательские контуры — в localStorage. Отдельные диалоги индексируются по аккаунту/гостю и ID зоны. Пользовательская серверная история также фильтруется по зоне.
- Backend заново рассчитывает показатели и проверяет соответствие OSM ID фактической геометрии. Контекст ИИ содержит ID, личное имя, исходное имя, статус и происхождение данных; тяжёлый массив схематических точек в AI не передаётся.
- Живой тест выявил модельный HTTP 403. Он больше не считается недействительным API-ключом: ограниченный fallback пробует разных бесплатных издателей, чтобы два отказа одного издателя не занимали все попытки. HTTP 401 останавливает запрос. Пустой текстовый ответ также запускает fallback; лимит ответа повышен до 1400 токенов, чтобы reasoning-модель успела вернуть текст.

## Мастер и локализация — 29.10.2026
- Мастер `/start` дополняет подробный `/plan`. Настройки применяются после «Составить план»; выбранная геометрия, параметры почвы и происхождение данных сохраняются. При генерации ручные количества заменяются автоматическим подбором.
- Цели shade/road/low_maintenance добавляют до 8 баллов за крону, среднее wind/salt или drought соответственно. Это прозрачная экспертная эвристика; критические исключения имеют приоритет. goal=children принудительно применяет детские ограничения на сервере.
- Объяснения хранятся канонически, переводятся при отображении по общему словарю, поэтому старые снимки расчётов можно читать на обоих языках без изменения чисел. Ошибки и экспорт используют Accept-Language. Сообщения пользователей, личные названия и прежние ответы ИИ не переписываются.
- Ближайшие улицы рассчитаны по открытому снимку и работают без внешнего геокодера. Адресные номера не назначаются; каждую привязку можно проверить по ссылке OSM.
